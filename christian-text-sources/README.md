# 基督教文献原始内容获取档案

本目录承接古代文献研究110条及 `research/modern-christian-resources` 的65条阶段性资源，共175条获取档案。当前优先执行近现代资源的内容获取，原研究目录保留。65条包括书籍、作者、事工、刊物与数字馆藏，不等于65本书。

- [总目录](CATALOG.md)：按书目查看获取状态和正文入口。
- [进度](progress.json)、[执行计划](PLAN.md)、[继续协议](CONTINUATION.md)、[队列](queue.json)：支持跨会话续接。
- `books/<稳定ID>/README.md`：每条独立档案；`record.json` 保存作品身份、版本、内容范围、核验过程、下一步。
- `inventory/source-catalog.json`：输入书目快照；`inventory/manifest.json` 保存来源提交号、SHA-256和全部档案路径；近现代输入快照与去重映射见 `inventory/modern-*`。
- `sessions/`：分阶段成果及真实停止位置；[阶段报告](REPORT.md)记录已取得和仍未取得的内容。

古代110条首轮定向检索已完成；近现代65条已加入队列，正按具体书版／单篇／单件推进。实时计数以[最新报告](REPORT.md)和progress.json为准；`queued` 表示尚未完成本轮内容检索，不能算已取得正文。

“原始内容”同时区分原作语文、古译、近现代外文译本；外文译本只作为转译或对照候选，不能冒充原作。完整作品、部分章节、残篇、作品集和书目介绍分列。仅返回HTTP 200、搜索摘要、出版社介绍或馆藏记录不能算取得正文。

本轮优先保存稳定在线正文及扫描入口，不批量下载全书。旧版文本可能更易取得，但译文范围和底本须明确。可在线阅读不意味着现代译文可以再分发或直接用于公开出版。

本项目不安装后台爬虫；每完成小批即存档并推送。用户发送“继续”时，按本目录协议续接，不重建已完成档案。

## 近现代导入与去重

运行 `python christian-text-sources/scripts/import_modern.py` 后再运行 `python christian-text-sources/scripts/report.py`。导入优先按来源目录+原ID识别；原ID改名时以规范化题名+完全相同的来源URL集合辅助去重。共享机构域名不能证明是同一作品。新增ID使用 `modern:` 前缀，避免与古代档案的B01、lb01等ID碰撞。来源原有3组重复已沿用合并结果并保存别名。

导入可重复执行，已存在的获取状态、尝试与正文资源不会覆盖；记录先于manifest落盘时，下次运行会恢复孤立记录。来源目录今后新增作品可再导入；已有来源书目的变动需另行版本审查，不自动覆盖旧快照和获取结果。
