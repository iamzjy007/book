# 执行路径与验收

## 范围

用户本轮指定近现代研究阶段成果，因此在保留古代110条的基础上，接入近现代目录65条去重资源。当前 `inventory/manifest.json.active_scope` 为 `modern-christian-resources`，优先取此来源队列；不执行原研究项目扩展书目的待办。

## 批次

1. 建档：冻结来源提交与目录哈希，110条各建独立档案；生成总目录、状态、队列和续接协议。完成即提交主分支。
2. 叙利亚／阿拉伯15项：先核优先短名单，再搜原文语料库、syri.ac、旧版扫描和可明确版源的译本。
3. 福音及使徒外典18项：从NASSCAL作品条目追到版本、实际正文或手稿；不把摘要当译文。
4. 东方修道／埃塞俄比亚／亚美尼亚／格鲁吉亚17项：版本与语种优先；Senodos先拆构件，Josippon必须是吉兹传统。
5. 希腊／拜占庭20项：逐作品确认全文、篇章和选集范围；现代Philokalia译本权利与希腊原文分开。
6. 拉丁西方19项、礼仪及殉道16项、纳戈玛第及相关5项：寻找原语旧校本与可核外译；已有仓库内容标明可复用。
7. 每批更新REPORT、queue、progress和会话日志，校验后提交并推送main，核远端SHA。最后集中复核受阻和仅书目条目，明确未取得原因。

## 每条检索路径

原题+作者+full text／edition／scan → 已有出处及其外链 → 大学、图书馆、原文语料库 → Internet Archive／Gallica／Google Books等扫描 → 可信旧译全文。失败时记录查询、访问结果、替代入口和精确下一步。不以没有搜索结果断言不存在。

## 状态规则

- `queued` 尚未进行本轮正文检索。
- `fulltext_online` 作品对应版本正文可直达，已打开并核题名／正文；只确认入口及结构，不表示逐页完整性校勘。
- `partial_online` 可直达的部分章节、选译或残篇；残篇作品若收齐现存部分仍须注明原书不存。
- `scan_candidate` 定位扫描或语料入口，但未核实足够页面／权限／覆盖范围。
- `metadata_only` 检索后仅确认版本或馆藏，未取得内容。
- `blocked` 找到可能正文但访问受阻。
- `needs_review` 版本身份或作品对应关系尚不能确认。

## 持久化与核验

record.json是唯一主数据；README、CATALOG、progress、queue由脚本重建。每条或每小批采用临时文件+原子替换写入，不依赖会话记忆。执行 `python christian-text-sources/scripts/refresh.py` 重建并校验ID、资源种类和必填版本字段。每次推送保留已存在远端修改，不强推、不删除原研究文件。

## 近现代获取批次

先冻结来源提交、SHA-256及65条导入映射，形成session009；随后按queue顺序，每3—5条记录实际打开的正文／样章／馆藏对象并保存小批成果。机构与作者入口保留父档案，通过永久URL、ISBN、篇名、卷期或馆藏号登记具体对象及范围；不能以一篇文章宣称全站或整套书全文取得。元数据与付费入口也保存，状态不升级为正文。古代未决条目保留，但当前默认“继续”优先本次近现代获取。
