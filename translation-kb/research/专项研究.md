# 词语检索与同一模型多轮审校

本研究考察两个问题。新文章只露出两个熟悉的词时，能否找回读者熟悉的和合本措辞？一稿大致正确时，同一模型再读两遍，能否指出值得修改的地方，也保住原来译得好的句子？前一个问题以词和局部上下文为单位，后一个问题以具体改动为单位。

**迁移到古代文献后的修正。** 在献祭用的贡税里分出一份，也会同时出现 *portion* 和 *Lord*。食物给人力量，也可能一连说两次 *strength*。这两种情形曾误触诗篇的“我的福分”和“避难所，是我们的力量”。现在分别检查领属关系及庇护线索，配有日常义与经文义的正反例。另一个问题出现在第二遍审校：若只看正文，模型可能把别章的惯例推翻本节已有校勘。作业可带上本节已经核实的版本说明；若要改变旧判断，须写明更直接的根据。旧作业仍可继续。

## 经文如何变成可查的用例

1. **按底本取证。** 中文用本库简体《新标点和合本》，英文用 WEB。108 条编辑整理的义项来自 23 卷、102 处经节。每条有英中文原片段、可识别的英语变体、邻词、排除条件和借用边界。构建时在两种底本的同一节逐一核验片段。比如歌罗西书 3:15 的 WEB 称 God，中文作“基督的平安”。可借“在你们心里作主”，平安属谁仍按待译原文。
2. **按全经用词找候选。** 将全部 31,098 个有正文的英文节位编入词形检索。另按节去重统计实词，以及相邻两实词之间最多夹两个虚词的搭配。一个搭配出现于至少三节、至少两章，最多三百节，实际同现率至少为两词独立出现预期的六倍，才进自动搭配表。本底本得到 3,161 个搭配。这些是英文检索键；整节中英对照供核实词义。单次出现的词和短语也能手动查全文。
3. **按新文章的局部语境消歧。** 编辑词条查看触发处左右各十二词，保留英文原片段，检查必要线索与排除项。另一路从全经搭配、属灵用词和较少见的单词寻找经节。新句中左右十词内的独立线索须在经节对应词左右八词内出现。单词候选需要两个额外线索；搭配候选也可凭一个足够少见的邻词入选。候选经节按邻词稀有度与搭配强度排序，同分优先诗篇、智慧书和保罗书信。逐篇预算限制自动检索数量；有疑问可以用手动查词扩大范围。
4. **交给译者做局部选择。** 高相关义项附中文短语、经文摘录和使用说明；统计共现只附双语原节和触发线索。一个句子可以一次找到诗篇 23:2 两个意象。作者只取半句，就只借相符的半句。人物、语气、应许的限定和有意改变的意象随本文。遇到日常用法允许零推荐。直接引经另有按章节目核对的入口。

## 从编译原理借来的三个做法

**给每次改写留下可检查的中间记录。** 每条提案记录英文段号和证据、中文段号、待换片段、拟用新句、谁做什么以及条件管到哪里。英文触发器标出可能有问题的位置，例如省略的谓语、条件从句和共享宾语；模型负责补全语义。程序能核对位置、底稿版本、锁定的文字及重叠修改。主语是否真的读对，仍需结合语境判断。

**每遍只给模型一个主要问题。** 语义轮从英文校到中文，先检查施受、人称、时间、否定和引经。朗读轮从中文读回英文，处理搭配、语序、重复与段内推进。定稿轮把上一轮修订与英文重新并排，寻找新引入的错误。审校涉及祷告、叙事、书信或人物对白时，先确定谁在说话；只有原作者以神的口吻说话才用神的第一人称。这种逐项处理、重新检查、稳定后停止的安排借鉴了 MLIR 的迭代改写。自然语言允许多种好译法，无法像程序那样证明两个译文完全等义。[MLIR 关于改写、收敛与循环的说明](https://mlir.llvm.org/docs/Canonicalization/)

**用对照例检验规则的适用边界。** “我没有说过日期”中否定落在“说过”；“我必不撇下你”否定的是行动。类似措辞进入不同结构，模型应有不同处理。评估记录错误所在和改动理由，并给模型相邻语句，借鉴了 MQM 文中按错误及文档上下文评估译文的方法，以及英汉代词、关联词、省略的对照测试。此处没有照搬论文的分数。[Freitag 等的评估研究](https://aclanthology.org/2021.tacl-1.87/) · [Cai 与 Xiong 的英汉篇章测试](https://aclanthology.org/2020.iwdp-1.3/)

## 实测二　同一模型能否在下一遍读出新问题

我取仓库已有的六段英中原稿，以现有中文为基线，由本次同一模型逐轮提交改动，并实际经过作业状态机。六段共作十处修改，其中三段在定稿对照时发现前轮还有问题。两段全程保留初稿。这是编辑实验，未经过用户盲评。可逐条查看英文、初稿、各轮差异、理由和最终采用的文字。[实验记录](revision-cases.json)

| 片段 | 各轮发现 |
|---|---|
| DYDI 001 | “我栽种他们”给英文被动句补了施事。朗读轮调整栽种与留下的顺序；再对照时补出“被”，让人作为受事更加明确。 |
| DYDI 200 | *if I told you it all* 描写听者，“目不暇接”误落在视觉；改成“听得晕头转向”。朗读轮处理“发明正在来到”，定稿轮再把过窄的“创意”改为“革新”。 |
| Lori 039 | 连用“让……使……”使读者难以把握目的。先分句，再发现“事到临头”带上原文没有的负面意味。最后从听者落笔，“等这些事临到，心里就有数，不至惊讶”。 |
| DYDI 428 | 保留“让我”统领的引导，末句改成“告诉你们该去了解谁、听谁的话”，解决“查看并聆听的是谁”的动宾搭配。 |
| Lori 129、132 | 前者保留评阅者确认的青草地和水边。后者的“我的孩子，我一定会”已承接“回答你”，不必为了显示审过而再次改写。 |

跨篇复用落实在两条新句法提示上。Lori 039 促成“连续目的句”；DYDI 428 促成“并列动词与宾语”。每条用不同英文写一条该触发和一条应忽略的对照例。以后遇到新评语，先在个案保留证据，再把能跨句复用的条件加入表，跑同一套回归。本书已确认的措辞仍保留其作品和语境范围。模型的自评记录是编辑意见。

## 无人值守的验收边界

任务库按篇保存。每轮写入前核验底稿标识以及锚点，修改和审校记录在同一个事务提交。重复答复可安全重放；过期答复、重叠修改或触动锁定措辞会被拒绝。定稿轮出现新问题后最多再走一轮；检测到往返改写或耗尽轮数时，留存草稿待复核。只有定稿对照交回零项修改才可导出。

本次检查覆盖词义双语出处、日常用词的误触、称谓切换、全经索引重建、六个真实片段的重放，以及无人值守接口遇到无效答复后重试、续跑和模型设置检查。接口测试使用本机模拟服务；六段译文判断由当时同一模型完成。评阅者对后续新文章的判断可按下面的方法另行记录。

## 实测三　惯用词都通过后，还漏得掉什么

对[固定题库](contrasts.json)中的每句英文，分别把两份中文候选交给正式的惯用词审校入口。每次只给一份中文，用词审校程序看不到题目答案。沿用已有的八组语义与语体对照，另加两组能靠译词辨认的 `armor` 对照，用来确认同一程序确实在工作。可在知识库根目录复跑：

```powershell
python -X utf8 research/contrast_trial.py --audit-terms
python -X utf8 research/meaning.py research/meaning-example.json
```

| 问题 | 题数 | 仅对有意改坏的一稿提示用词待核 | 两稿都没有用词待核项 |
| --- | ---: | ---: | ---: |
| 已收录的两种 armor 用法 | 2 | 2 | 0 |
| 施受倒置、条件、否定、说话者、或然语气、意象改变 | 6 | 0 | 6 |
| 朗读节奏与文白语体，按本项目编辑偏好 | 2 | 0 | 2 |

“你们穿戴我的盔甲”触发了“军装”，“带上光明的军装”触发了“光明的兵器”。同样熟悉的圣经词汇也可以遮住大错：测试句特意让以撒捆绑亚伯拉罕，把它译回通常叙事中的“亚伯拉罕捆绑以撒”，用词检查仍给零项。表中八组同分只表示这个程序没有区别两稿；其他审校步骤与读者可能看得出差别。八组题仍按原来的随机种子生成独立盲读题，两组词义对照只用于本项诊断。

否定例可以进一步定位。运行第二条命令，忠实候选返回零处分歧；另一稿报出“应许”和“开门”两处否定位置的变化。这里的命题和否定标注是预先给出的。这验证了比较程序能指出标注差别；模型自行读出这层意思的能力还要另测。十组均为编辑设计的诊断题，本轮没有调用外部模型或收集盲评票。

## 下一轮　把二审、三审的收益落到一处处改动

1. **先留样。** 两本书各取四个尚未评过的段落。先固定篇号、段落、原文版本和底稿，再生成模型答复。排除参与造规则的篇章、同文重刊和新稿已有的同段译例。由一位评阅者先在英文和初稿上圈出能确定的漏义与错义，把判断暂存，评阅时一并复查。
2. **同一模型做两组。** 两组从同一份初稿出发，使用相同模型版本、上下文和审校轮数。甲组用普通翻译包，乙组使用相同包，另在疑难句先还原“谁说、谁做、落在谁身上、否定或条件管到哪里”。保留三轮译稿及每处理由，记录实际提示字数和调用次数。需要判断串珠的增益时再单开一轮，只切换串珠。
3. **一人也能盲读。** 对每一段，把相邻两轮译文的顺序随机调换，隐藏组别、轮次和修改理由。评阅者先只读中文，记偏好或平局；再对照英文，按位置标出修复、误改、仍遗漏的原义及可保留的旧译。完全相同的两稿记平，未触及的已知错误仍计遗漏。揭开顺序后再计算哪一轮有进步。
4. **按篇判读。** 二审比一审、三审比二审分别报告“解决几处旧错、引入几处新错、余下几处已知错”和朗读胜／平／负。逐轮净改善取修复数减误改数，同时单列说话人、施受、条件或应许强度等严重改坏。若系统已经报收敛却仍有这类问题，记一次提前收敛。重复换词后又退回旧译，也单列为往返改写。这一小批先决定哪些句子值得增加语义复核；扩大应用前换另一批新段复测。
