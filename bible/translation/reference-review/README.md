# 信望爱次经参考修订

用户指定入口：https://bible.fhl.net/gbdoc/new/readsub.html 。实际章节访问使用同站可用域名 `https://bkbible.fhl.net/gbdoc/new/readsub.php`，各卷记录保留实际网址。

页面有 `c1933`（1933年圣公会出版经文）与 `chdc`（1933年次经全书经文）两列。两列有重复译文、分节及录入差异，不将它们默认当作两个独立译本或两份独立校勘证据。

## 范围与方法

按实际内容将网站的多比传、犹滴传、所罗门智训、便西拉智训、巴录书、马加比两书、以斯拉两书、以斯帖补编、玛拿西祷言及但以理补篇对应至仓库。《耶利米书信》实际收在本底本 `1-baruch/c94V`，位于巴录5章之后（p0011为标题，p0012—p0084为正文）；它不是正典《耶利米书》。正典66卷不属于本轮修订。

逐章阅读英文、现有中文及参考中文，重点核对主宾关系、指代、否定、条件、时间、古义及自然表达；根据底本独立改译。保留已经准确自然的句子，不以靠近参考为修改目的，不机械统一专名或替换神名。总体遵循原有庄重、凝练、接近和合本的风格，忠实优先。

网站章号、节号与英文可能不一致，必须按内容定位；缺页、错页或录入缺文如实记录，不把获取网页等同于完成审校。不以中文参考擅自补删不同底本的内容，也不将参考全文收入仓库。

各工作者 JSON 记录实际核读范围、章节网址、修改前后及理由、保留的差异和结构验证结果。它们是本轮修订断点，原工程的 `reviewed` 标记不表示已经做过本轮参考核对。

使徒教父网站的另一路修订记录见 [history-patristics/reference-review](../history-patristics/reference-review/README.md)；其中《十二使徒遗训》《巴拿巴书信》《黑马牧人书》的正式译文仍在本工程目录。

## 本轮结果（2026-11-09）

12个次经书卷／合集条目、186个源文件单元已完成本轮核读与修订，改动113个正文块；正式JSON与分卷TXT已同步，源指纹、块顺序及完整性验证通过。没有改动正典66卷。与使徒教父参考修订合计22项、469单元、214个正文块，分卷统计及TXT指纹见 [summary.json](summary.json)。单元数不是网站章数；不将无对应中文的部分计为三方核对。

《以斯拉一书》的参考覆盖有限：网站第3、4章有完整对应中文，第5章仅1—6节，第1章使用平行经文摘录，第2及6—9章只有转引或未返回正文。全部九章英文与现译已校读，具体证据见 `fhl-dydi-d.json`；不能据此声称全部九章都有完整中文参考。

《以斯帖补编》参考第6章1—10节的解梦段不在指定英文的本卷范围内，没有将它当作漏译补入。其第6章11节则对应英文置于卷首的11:1。其他分节、数字、专名、否定及从句归属的差异保存在逐章记录，尚不能确定的解释保留简注，不用参考译本掩盖疑义。
