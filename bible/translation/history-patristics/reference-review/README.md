# 信望爱《使徒教父著作》参考修订

参考：黄锡木主编，黄锡木、张略原文审校，陈宝婵、彭惠敏、邱丹、王碧燕编译，信望爱阅读页面 https://bkbible.fhl.net/gbdoc/AF/readaf.html 。实际章节链接为同目录 readaf.php。

本轮核对范围是网站与仓库的对应作品，不将使徒教父选集冒称为覆盖全部54项历史教父作品。网站的《十二使徒遗训》《巴拿巴书信》《黑马牧人书》对应此前典外工程；革利免两书、伊格那丢七书、坡旅甲书信及殉道记、致丢格那妥书、帕皮亚残篇对应历史教父工程。残篇须按内容对齐，不按序号硬套。

方法：逐章读取参考译文、指定英文底本与本地译文；借助中文参考发现逻辑、指代、词义或句式问题，再从英文独立形成修订。保留底本的实际内容、语气、否定和特殊引经；版本差异记录而不擅补。已有准确自然的句子保留。参考译本的中文全文不纳入仓库。

禁止脱离语境的批量词语替换，尤其神名、主、主人、职分和教义术语。程序仅用于读取、定位、保存和完整性校验。参考页存在并不意味着已经核读，报告只登记实际检查范围。具体改译、未采用的参考读法和核对记录见各工作者JSON。

本目录记录的是此次参考修订证据；原项目reviewed标记不是一次新的独立原文校勘证明。
