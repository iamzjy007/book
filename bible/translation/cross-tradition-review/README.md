## 证据与处理原则

1. 区分宗派正典、礼仪诵读、历史文献三种地位；不因书名出现在某个网上合集，就判定为该教会正典。不改动此前排除的正典66卷。
2. 记录实际查阅的网址、出版／编译机构、译者、年代、底本／语言和具体对应范围。教会认可、学术校勘价值、中文表达价值分别判断，不笼统冠以“权威”。
3. 查明独立性。同一ANF／NPNF英译在New Advent、CCEL等站转载，不算两个独立译本；同一中文译本的两种排版亦然。
4. 指定底本控制范围。中文参考帮助发现歧义、错译、旧义和句法问题；回到本书上下文独立措辞。不同文本传统的增删、姓名、数字、否定和编次必须记录，不悄悄拼成一个新底本。明确的英文录入错误有充分证据时可修正并简注；证据不足则保留待核。
5. 《雅煞珥书》另有用户指定的1987年希伯来工作底本、1625年对校本；不得在本轮重新降为英文优先，也不得把此前自动替换形成的稿件称为完成希伯来全文校勘。
6. 延续现有和合本式、庄重自然的文风。借鉴思高等译本的语义和句式，不机械更换天主／神、宗徒／使徒、人名或神学术语；历史记述、论辩和书信保持各自语体。不脱离语境批量替换。
7. 网上参考原文留在忽略跟踪的缓存中；仓库只保留书目、链接、核对位置、必要短引及本项目改译记录。未经实际阅读不宣称已参考，不把摘要、目录或搜索片段当作全文。

## 断点与完成程度

每位工作者使用独立记录，登记资源研究、实际核对的源单元／块、修订前后及理由、保留的异读、尚待处理的位置。`coverage.json` 汇总实际证据，不以认领状态判断任务正在运行。

“资源已确认”“重点段落已核对”“全文已核对”分别记录。结构验证只证明源指纹、块次序和文本完整性，不证明翻译无误。不能保证“尽善尽美”，也不将某一轮抽核冒称为全部作品已做多译本全文校勘。

由主工作者统一交叉复核、汇编TXT并提交推送。中断时保留已经完成的文件和实际断点；后续从记录续接，不清空既有成果。
