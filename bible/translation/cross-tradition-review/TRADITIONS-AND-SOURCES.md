# 收录传统、译本及文本证据

核查日期：2026-11-09。此说明用于选择参考和判断异文，不替读者决定信仰立场。

## 收录地位须分开判断

| 传统／文件 | 可确认的范围 | 对本项目的意义 |

本仓库英文EPUB的元数据署名及出版者为Dunatos Publishing，日期为2025-06-26。它是本项目指定的翻译对象；现有核查材料不足以把整部合集认定为埃塞俄比亚教会正式批准的经书版本。合集名称、其中各作品的实际年代和宗派收录地位应分开记录。

## 本轮如何选用参考

中文译本主要帮助辨识语义、长句关系和自然庄重的中文措辞。思高的教会背景与语言价值均应重视，但不因此全局替换已有的“神／使徒”等称谓，也不将思高采用的另一底本读法偷偷并入本项目。出版目录只能证明书目；无法取得正文时，不能记录为已对读。

原文校订本、校记与有明确译者的独立译本用于判断读法。NETS提供具体译者和所据希腊校订本；必须读各卷导论。例如多比的长短本、但以理的不同希腊传统，需要分别定位。NETS的《Esdras B》与本项目称为《以斯拉二书》的启示性作品也不能仅凭“2”字混同。[NETS出版说明与分卷入口](https://septuaginta.uni-goettingen.de/ioscs/nets/edition/)

教父作品须落实到具体作品、书信、段落与译者。CCEL、New Advent或其他网站可能转载同一ANF／NPNF英译；网址不同不构成独立证据。同一旧译的明确缺字、误译可借其他译本和原文核实；若属于古抄本异读、长短本或编者校正，应保留差异说明。

译本不是简单的优劣排名。较顺的译文可能采用不同底本；较早的印本也未必字字更可靠；印本年代、原作年代与翻译年代必须分开。凡实际改译都应能回答：原稿哪一处有问题、依据哪种文本、为什么不是另一种可成立的读法。

### 本轮实际使用的主要参考体系

| 参考体系 | 主要价值 | 使用边界 |
|---|---|---|
| 思高1968合订本及学会官网中文本 | 多比、犹滴、智慧、德训、巴录等的语义、句法及庄重中文 | 只记录已打开并读过的章节；保留本项目神名、译名体系；不照搬不同底本的增删 |
| USCCB发布的NABRE、NRSVUE及其版本说明 | 现代释义、文本问题注、不同古译之间的关系 | 部分页面访问失败；RSV、NRSV、NRSVUE有继承关系，不能重复计算独立证据 |
| NETS及各卷导论、脚注 | 明示希腊校本、译者和校改；可区分多比GI/GII、但以理OG/狄奥多田、以斯帖OG/Alpha | 思路与NRSV有联系；现代校订本的拟改不等同所有古抄本一致如此 |
| UBS译者手册，SIL获许可展示 | 解释难句与校勘争议，有助于判断是翻译问题还是文本问题 | 是研究工具，不是额外的古抄本；本轮实读篇目见 `dydi_a.json` |
| Lake的Loeb希英对照、Lightfoot／Harmer、Hoole等使徒教父译本 | 对照希腊印刷正文及校记，查漏译、否定、比喻和传本差异 | 印刷英译也可能出错；《巴拿巴书信》“衣袍／医治”等须看校记，不能只比较译文数量 |
| ANF／NPNF与可核对的拉丁文本、其他独立译本 | 教父书信、法令、教会史的句法、术语及作者归属 | 网络镜像不增加独立性；伪托作品保留历史署名，但应说明现有归属疑点 |
| Charles编APOT、James、Pick等旧刊与现代专题研究 | 追溯英文来源、检验录入错误、辨析伪经及使徒行传的传本 | 老译、现代英译、古语原文是不同层次；保留疑难和校者拟改的标识，不将缺文补成确定事实 |

具体链接、译者、年代、已读页码与章段均见各工作记录。已知中文出版物若仅取得书目或目录，只能列为后续线索；例如所查奥古斯丁《书信集》中文第一卷目录为第1—50信，不能据此声称第208信已用该中文版对读。

## 修订的四种结果

- **译义修正：** 底本不变，修正主宾、指代、否定、条件、古义或明显不自然的表达。
- **底本疑错修正：** 有原文／明确版本及上下文证据，按用户授权改译，并在译者注保留原读法及理由。
- **真实异读保留：** 不把另一版本的内容当成现稿漏译；必要时短注说明。
- **证据不足暂留：** 记录待核位置与所缺证据，不把个人偏好写成“已核实”，不为了追求完美制造确定性。

本轮逐项记录及覆盖表的完成程度，均按实际阅读和复核范围计算。资源研究、重点审校、全文校勘是不同的工作，不能互相替代。
