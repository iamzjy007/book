# 塞巴斯特四十殉道者遗嘱：校译附记

## B. 待核清单

以下均为未决事项；“全文译毕并自校”不表示这些问题已解决。工作音译以本版词形为依据，不冒称中文通行定译。

| 位置、原文片段 | 问题 | 当前处理方式与下一步 |
|---|---|---|
| 题名 `τελειωθέντων` | 在殉道语境可作“成全／走完路程／殉道而终”；题署不等于成文年代或作者身份已获证实。 | 题名作“成全”，保留题署与正文自称；真实成文、署名及传承待核。 |
| 问安 `⟨τοῖς⟩` | 主文以尖括号补出致书对象的与格冠词。 | 中文对应作“〔拟补：致〕”，不隐去底本的补字。 |
| I.1 印页166行17—18 `τὰ λείψανα ἡμῶν`；校注 `coni. ἀδιακρίτως Ms.` | 第二次出现的“我们的遗骸”是校者猜改，Mendelssohn另拟“不加区分”；第一次出现不是这条校注对象。 | 正文第二处作“将〔拟补：我们的遗骸〕安放”；不把第一次出现误标为拟补。需与抄本及后续校本比对。 |
| I.1 `τὴν πόλιν Ζήλων ... Σαρείν`；注 `fort. πολύζηλον (sc. ἐκκλησίαν)`、`Σαρεῖμ Bn.` | “泽拉城”本身有另一猜读，可能涉及教会称谓；村名末辅音亦有异读。 | 按本版主文暂译“泽拉城下方的萨雷因村”，正文标待核；不将另一拟读拼入主文，也不擅定现代地名。 |
| I.1 `πατέρα ἡμῶν Πρόϊδον` | πατήρ可能是教会尊称，不能因此判定生父关系。 | 暂作“父辈普罗伊多斯”，与长老职称并保留；具体身份待核。 |
| I.1、III.1 `Γόρδον`；III.2 `Γόρδιον` | 所选主文词形有差别，不应静默全局统一。 | I.1及III.1作戈尔东，III.2作戈尔狄奥斯；人物对应及通行音译待核。 |
| I.2 `τοὺς λοιποὺς ... παρακαλοῦμεν τοὺς κυρίους ἡμῶν γονεῖς καὶ ἀδελφούς`；注 `codd., corr. Bn.` | 抄本格位与校本改正不同；Aetios、Eutychios及其他弟兄的分组，不能据此增加人物关系。 | 按本版句法译“我们这些与……在一起的人”；“恳请……父母、弟兄”标拟补，提示该分句采用校者整理。抄本句法待核。 |
| I.3 `ἓν ἑαυτῷ`；注 `ἓν Hr.] ἐν codd.` | 校者以“一份／一个”改抄本“在”；不是后文“一同聚集”的改读。 | 正文作“不可将〔拟补：其中一份〕私自留下”，保留禁令，未为遗骸添加圣物功效。改读所据的抄本句法待核。 |
| I.4 `μικρῷ βουλήματι`；注另拟 `μικρῷ λήμματι`、`μιαρῷ βουλήματι` | 可涉及微小私意、微利或污秽意图的差别。 | 守主文“微小的私意”，不采“为一点钱财”或“邪恶意图”；词义及句法待核。 |
| I.5 `ὁ παῖς Εὐνοϊκός ... μετ’ ἐλευθερίας ... τῷ μαρτυρίῳ ἡμῶν` | παῖς可为少年或仆役；“自由”可能有法律身份意味；μαρτύριον可涉及殉道见证或纪念处。 | 暂作“童仆”“以自由之身〔身份待核〕专心记念我们的殉道”；不另补正式释放文书、建堂或守墓职分。 |
| I.5 `ἠξίωσεν` | 过去时动词夹在将来条件句中，主语衔接不顺。 | 结合上下文共同遗愿，暂作“我们愿他与我们同葬”；时态和省略主语待异本核定，不写成神已经命令同葬。 |
| I.5 `ἀπολαύσεως` | 词形为享用、享受，不是ἀπολύσεως“释放”。 | 已按页图自校为“同享福乐”，不据近形误译释放。具体所享之物原文未展开，中文不增天上冠冕等细节。 |
| I.6 `Ὁ ἀγαπῶν τὴν ἀδικίαν μισεῖ τὴν ἑαυτοῦ ψυχήν` | 与七十士译本诗篇的措辞相关；本版旁注Ps.10,5不等于和合本同号、同文。 | 直接按本段希腊引文译出，不用和合本“神恨恶……”替换；编号对照见下表，未将编者章节补入正文。 |
| II.1 `ἀδελφὲ Κρισπῖνε *`；注 `uidetur hic deesse nomen Gordii` | 校者引述Lambeck怀疑此处缺Gordios之名，尚不能当作实存正文。 | 正文标“此处校者疑脱人名，待核”；未添戈尔狄奥斯，未将“疑缺”写成已证实的〔缺文〕。确认确有缺损后方改用〔缺文〕；推测人名须作〔拟补〕。 |
| II.2 `ἀπροφάσιστον ... τῆς πολιτείας τὴν πρᾶξιν`、`εἰ ἐγνώρισας ... ἐν αὐτῇ ... ἐν αὐτῷ` | 行事、推诿、时间与指代的关系不顺；注另拟ἐν αὐτῷ，主文未采。 | 保留本版的条件“若”及基本指向，正文标句法待核；不将语义困难擅标缺文，也不把“若”删成确定陈述。 |
| II.2 `Ἐν ᾧ γὰρ εὕρω σε ... ἐν τούτῳ καὶ κρινῶ σε` | 是引语，本版仅参Resch《Agrapha》；不能确定为正典圣经某节。 | 译出并标“引文出处待核”，保留“他说”；不编造福音书章节，不套用和合本不相干经文。 |
| II.3 `καὶ αἰώνιον` | Bonwetsch对“且永远”有删文意见，本版仍印入主文。 | 译“不息而永远的火”；校注方括号属于另一编辑意见，不将它误当存世缺文或本版补文。 |
| II.4 `οὐχὶ τῇ φύσει ... ἀλλὰ τῇ ἀρίστῃ πράξει ...` | 作者自己的否定、转折与太12:50并非同句，不能为经文熟悉度而改写。 | 保留原文对天然关系与行为、信仰、旨意的对举；不补入“姐妹和母亲”等本段没有的称谓。 |
| III.1—3 `μετὰ τῶν ἰδίων`、`νύμφην μου Βασιλείαν` | οἱ ἴδιοι是所属之人，不一定只限血亲；νύμφη可指儿媳、新妇，语境亦可能是姻亲。 | 前者暂作家人；后者暂作“儿媳〔亲属称谓待核〕”，保留儿媳／姻亲／新妇三种候选，不据人名补婚姻史。 |
| III.2 `Ἀέτιος Hr. ...] Μελέτιος codd.` | 本版将抄本第二次“梅勒提奥斯”改作“艾提奥斯”，属编辑改读。 | 正文“我〔拟补：艾提奥斯〕”，不当作毫无争议的发言人；校本简称Hr.指Haussleiter。 |
| III.3 `Σαπρίκιον ⟨τὸν τοῦ⟩ Ἀμμωνίου`；注 `ἀμμώνιον codd.` | 本版以补字将两个并列姓名改为父子关系；抄本也可读作另一位阿摩尼奥斯。 | 采用主文时将整项“〔拟补：阿摩尼奥斯的儿子〕”显标；未凭I.1的相同关系消除III.3的文本问题。 |
| III.4 `οἱ κύριοι ἡμῶν` | 主格形式插在问安句中，与呼格或宾格不协调；Bonwetsch改排并删去该称呼。 | 保留其尊称信息作“诸位尊长”，标称呼句法待核；不删掉或误译为四十人自称主宰。 |
| III.4 `Βικράτιος, ὁ καὶ Βιβιανός`、`Λεόντιος, ὁ καὶ Θεόκτιστος` | 两个别名不能增加名册人数；Σακέρδων在名册中是姓名，虽与祭司称谓相关也不宜强译成职称。 | 各算一人，保持四十人次序；Σακέρδων作萨凯尔东。附四十人逐项对应表，异本专名待核。 |
| III.4 `ψυχῇ δὲ καὶ πνεύματι θείῳ` | 心灵与神的灵的关系未详释，不宜扩写成后世完整祷告公式。 | 暂译“以心灵、藉神的灵祈求”；语法及灵的称谓待核，不添加“三位一体”等原文没有的说明。 |

## D. 本次所依据的底本信息

- 主底本：Oscar von Gebhardt编，*Acta martyrum selecta*，Berlin: Verlag von Alexander Duncker，1902，第XVI项，印页166—170，希腊文题署、问安及I—III章14个编号段，含末尾签署、祈求和阿们。问安另计技术单元S，共15单元。
- 直接据所列希腊文校本翻译，未据现代英语、俄语、法语或德语译本转译；德文序言只用于版本说明。校者猜改和本次采用的句法整理以〔拟补〕标示，不声称所选主文即未受编辑的手稿原文。

- 序言VIII—IX说明：此遗嘱以Bonwetsch文本为基础，并用了Gebhardt自己的维也纳抄本校对，以及H. Omont提供的巴黎抄本比对。序言所引是*Studien zur Geschichte der Theologie u. Kirche*卷I，Leipzig 1898，页75及以下；并说明向Omont求校时尚不知Bonwetsch利用巴黎抄本的第二版。本次只确认序言这样记载，未直接查验两份抄本，也未亲核Bonwetsch两版；不把紧接着论第XVII项所列的手稿号套用于遗嘱。
- `Bn.`为Bonwetsch，`Hr.`为Haussleiter，`Ms.`为Mendelssohn，`L.`为Lambeck；简称依全卷缩写表核读（n16，见source.json），不是另取现代译者。
