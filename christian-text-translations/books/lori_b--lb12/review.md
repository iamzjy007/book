# 居普良案录：校译附记

## B. 待核清单

| 位置、原文片段 | 问题 | 当前处理方式与下一步 |
|---|---|---|
| I.1 `de nomine tuo` | nomen可能涉及姓名，也可能涉及基督徒名号／身份。 | 暂译“你的名号”，未另补总督已认定的罪名。具体法律语用待核。 |
| I.2 `pro nobis` | 底本清晰作“为我们”，不能依某些外译改作“为你”。 | 保留“为我们自己”；不作无依据纠错。版本比较待核。 |
| I.3 `Bona uoluntas, quae deum nouit` | “心意认识神”属拟人式语法；有译成“神所认可的善意”的读法，但那不是本版主文直译。 | 保留主动“认识神的善良心意”，不倒转主客体。措辞及异读待核。 |
| I.6 `delatores non esse` | 陈述有关告密者的法律原则，是否对应具体敕令，本文未说明。 | 仅译该陈述，不补罗马法律条文、年代或判定其法律准确性。出处待核。 |
| II.2 `ex sacro praecepto` / `sicut illi ostensum fuerat` | 前者是帝国命令用语；后者没有明说由谁、以何种方式显明。 | 分别作“遵照皇命”“正如先前向他显明的那样”；不增神谕、梦境或说话人物。显明方式待核。 |
| II.3 `principes duo ... strator ... equistrator a custodiis`；II.6 `principem et stratorem` | 罗马官署职名的制度对应，及II.6指一人兼任还是其他结构，需专业核对。 | 以“两名官员”“马官”“负责警卫的骑马官”“首吏兼马官”暂译，保留其差别，不增“骑兵队长”等军衔。职级与句法待核。 |
| II.4、III.1、V.2 `in Sexti` / `ad Sexti` / `agrum Sexti` | 前两处为省略式地名，不能肯定是同一庄园的哪些具体建筑。 | 前两处作“塞克斯图斯处”，V.2按agrum作“田地”；不补园主生平或所有权史。地点待核。 |
| II.6 `clarissimi uiri` | 罗马社会等级荣衔，不单是性格评价。 | 作“尊贵的”，修饰总督；未据此增入具体爵级。称号制度待核。 |
| II.6 `uico ... Saturni inter Veneream et Salutariam` | Venerea和Salutaria省略受词，尚未核是街、神庙或地段。 | 保留工作音译，不补“庙”或“街”。确切地理指向待核。 |
| II.7 `custodiri puellas`；校注 `al. castigari` | 主文是“照看／保护少女”，另有“约束／劝诫”异读。puellae未必特指奉献童女。 | 按主文作“照看好少女们”；不改成责备，也不增修会身份。异读与群体身份待核。 |
| III.2 `atrio Sauciolo`；校注 `Saucio, Secutiolo, Saloutio` | 地名多种异读，现代定位不明。 | 按主文作“萨乌基奥卢斯中庭”；待核，不以某个候选强行复原。 |
| III.4 `papam te`；校注 `coni. papatem R.` | papa是“父”的称呼及主教尊称；此处不可径等同后世罗马教宗专名。校注另有猜改。 | 按主文作“父”，不采猜改；不译“教皇”。语用及称号史待核。 |
| IV.1 `uix et aegre` | 可指吃力、勉强，也可能被解释成迟疑；原因未说明。 | 保留“勉强而吃力”，不补因病、内疚或同情的因果。原因待核。 |
| IV.1 `sacris legibus`；校注 `religionibus sacris Hl.` | 主文说神圣法律，外译有用宗教祭仪者。 | 按主文“神圣法律”；不与外译拼接。 |
| V.2 `lacerna byrro`；页下注服饰异读 | 两衣名及格位关系生硬，可能是同一披衣的不同说法；不宜凭OCR判作两件独立衣物。 | 以“外披的斗篷”暂译，另保留V.3长衣与麻衣的次序。服饰结构、名称和异读待核。 |
| V.3 `dalmatica` / `linea` | 历史服饰，不应自动译成后世主教专用祭服。 | 作“达尔马提卡长衣”“麻衣”；未附加礼仪用途。具体形制待核。 |
| V.7 `propter gentilium curiositatem` | curiositas可指好奇、窥看等；本文不交代此因果的具体经过。 | 作“因外教人的窥看，被放在近处”；不增“避免围观”“抢夺遗体”等目的。细节待核。 |
| V.8 `areas ... procuratoris` / `cum uoto et triumpho magno` | area在基督徒葬地语境的专义；procurator具体职务和votum礼仪含义未定。 | 暂作“墓地”“管理官”“以虔敬和盛大的凯旋之礼”；不补官阶、誓愿内容或沿途礼仪。词义与制度待核。 |
| 全篇人名、地名 | 多数采用工作音译，尚未系统核既有中文译名。 | 以本次固定写法保持全篇一致；有依据再修订，待核。 |

### 底本编者经文参照（不是案录正文）

印页124脚注保留：I.2“造天、地、海和其中万物”处 `cf. Ex. 20,11 etc. Act. 4,24. 14,15`，即“参：出20:11等；徒4:24、14:15”；祷告处 `cf. I Tim. 2,1s.`，即“参：提前2:1及下节”。这些由1902版编者列出，不能伪装成居普良亲口报出的章节。本次按拉丁句子翻译，未整句套用和合本。

## C. 术语表增补建议

| 原词 | 可选译法 | 本次选择与理由 |
|---|---|---|
| episcopus / presbyter | 主教／监督；长老／司铎 | 主教、长老：按历史职分区别，不把二者合并为牧师。 |
| subdiaconus | 副执事／襄礼员 | 副执事：保持原职名与diaconus的层级区别。 |
| papa | 父／教父式尊称／教宗 | 父：此处未限定罗马教宗；本段语用待核。 |
| disciplina | 规训／法纪／教导 | I.7“规训”，IV.2“法纪”：保留发言人的制度语境差别。 |
| sacratissimus（帝王尊称） | 至圣／至尊 | 至圣：显明原判词所用宗教化尊称，不代表译者认可其神圣性。 |
| gentiles | 外教人／异教徒／外邦人 | 外教人：此处按宗教区别，避免误作非犹太民族总称。 |
| aureus | 金币／奥雷乌斯金币 | 金币：不在未核币制时附加金重与现代币值。 |
| strator / equistrator | 马官／骑马侍从／骑马官 | 当前暂译见B项，待官制证据再定。 |
