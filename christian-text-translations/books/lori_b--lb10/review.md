# 游斯丁及同伴殉道案录：校译附记

## B. 待核清单

| 位置、原文片段 | 问题 | 当前处理方式与下一步 |
|---|---|---|
| 标题及全篇 `Ἰουστῖνος ... Λιβεριανός` | 希腊主文列七位人物；网站所列Dods英译标题并不逐一列齐。 | 标题按希腊文全部译出，不从英译标题删人。人名为工作音译，既有中文定译待核。 |
| II.4 `μετὰ δόγματος ὀρθοῦ` | δόγμα在此可指信念、教义、判断；不宜直接套用后世大公会议信条的技术义。 | 作“按正确的信念”；具体哲学、宗教语用待核。 |
| II.5 `παῖδα θεοῦ`；II.7 `θεοῦ υἱὸν` | παῖς本身可指仆人或孩子；同一发言后面明确以υἱός称他。 | 依据本段后文，暂作“神的儿子”；另列“神的仆人”为合理选项，不宣称παῖς只有儿子一义。原称号层次及异本待核。 |
| II.5 `καλῶν μαθημάτων`；校注 `μαθημάτων M.] μαθητῶν codd.` | 校本采校者改读“教训”，抄本作“门徒”；不能把改读当无争议原文。 | 正文作“教导〔拟补：美善的教训〕”，明确拟补。若守抄本可作“美善门徒的教师”；最终取舍待核。 |
| II.6 `προφητικήν τινα δύναμιν ὁμολογῶν` | “一种先知的能力”究竟归属于谁、与前后句怎样衔接，不够明晰。 | 保留不定“一种”及原句的承认语气，不增“基督赐我预言能力”等说明。指向、句读待核。 |
| III.3 `Μαρτίνου τοῦ Τιμοθίνου βαλανείου`；校注 `τιμιοτίνου codd.` | 人名、浴场名及属格关系有异读，无法凭该页确定地理关系。 | 正文暂作“某位马尔提努斯的提摩提努斯浴场楼上〔待核〕”；不补地图位置、街道或人物父子关系。需比异本和地名资料。 |
| III.3 `[καὶ] οὐ γινώσκων` | 方括号καὶ与分词的传承有句法问题；方括号在此不能自动当成缺文。 | 中文保留核心叙述，未为这一个连接词另增人物或事件，也未伪标〔缺文〕。本版删文体例与句法待核。 |
| IV.3 `δοῦλος Καίσαρος` / `ἐλευθερωθεὶς ὑπὸ Χριστοῦ` | 法律上的奴仆身份与“蒙基督释放”是不同层次。 | 两项都保留，不推断他已获得罗马法律意义的自由身。身份史待核。 |
| IV.8 `Ἰκονίου τῆς Φρυγίας` | 古代地区称谓不一定符合后世行政区划。 | 按底本“弗吕家境内的以哥念”，不擅改成吕高尼。地理称谓背景待核。 |
| V.2 `δώματα scripsi] δόγματα codd., δόματα O.` | Gebhardt明言改作δώματα；抄本δόγματα可作“教训”，另一改读δόματα是“恩赐”。δώματα与δόματα不能混读。 | 按所选主文暂译“〔拟补：他的居所〕”，不照旧英译悄译“恩赐”。具体词形、校者改读及其上下文合理性待核。后句χάρισμα另按“恩赐”译，不把两词合并。 |
| V.2 `μέχρι τῆς ἐκπληρώσεως τοῦ παντὸς κόσμου` | 世界“终结／完成”的语义与教义解释不能混同。 | 取“整个世界的终结”，不增具体末世时间表。语义层次待核。 |
| V.6 `Δι᾽ εὐχῆς ἔχομεν ... τιμωρηθέντες σωθῆναι` | 句法可向祈求、愿望或藉祷告得救倾斜；不能凭旧英译就把它写成无条件保证。 | 暂作“藉着祈求，我们能……在受刑以后得救”；保留διὰ τὸν κύριον“因我们的主”，不改成单因受苦即得救。句法、受刑与救恩的关系待核。 |
| VI.1 `δοξασθέντες τὸν θεόν` | 印本明确是被动态形态，后接宾格“神”不顺；通常所预期主动词形为δοξάσαντες。 | 正文作“〔拟补：颂赞了神〕”；这属句法复原，未当确定原文写入。是否印误及抄本读法待核。 |
| 章段关系 | 所选希腊版为I—VI六章；仓库所列Dods英译为I—V五章。 | 保留六章32段，不强凑英译章号；参见下方对应表。精确recension名称待手稿及新版校勘核定，本次不强定。 |

## C. 术语表增补建议

| 原词 | 可选译法 | 本次选择与理由 |
|---|---|---|
| ἔπαρχος（罗马城） | 城长官／城市长官／总督 | 罗马城长官，后文简称城长官：不与拉丁proconsul合并。 |
| λόγος（学说语境） | 学说／言论／道理 | 学说或教训：此处不是每次都指位格化“道”。 |
| δόγμα | 信念／教义／判断 | 信念：保留本段认同与遵从的语境，不预定后世教义定义。 |
| παῖς θεοῦ | 神的儿子／神的仆人 | 本段暂用儿子，依据II.7的υἱός；争议见B项。 |
| ὁμολογία | 信仰告白／承认 | IV.6信仰告白；结尾作“承认救主”，保持名词与行为区别。 |
| δῶμα / δόμα / δόγμα | 居所／恩赐／教训 | 严格分词形；V.2按所选校者拟改作居所并标拟补，不能机械套旧英译。 |
| παρρησία | 坦然无惧／放胆 | V.6作坦然无惧，置于审判台语境，不添免责解释。 |
| σπένδειν | 奠酒／行奠祭 | 奠酒：与后文θύειν“献祭”保留动词差别。 |
