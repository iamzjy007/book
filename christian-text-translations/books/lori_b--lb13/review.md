## C. 术语表增补建议

| 原词 | 可选译法 | 本批取舍及理由 |
|---|---|---|
| καθολικὴ ἐκκλησία | 大公教会／普世教会／公教会 | 暂“大公教会”，不预判后世宗派归属；IX章自称与排他性措辞仍须按原句核。 |
| ὁμολογήτρια | 女性认信者／认信者 | 以既有ὁμολογητής“认信者”为准；姓名已指明人物，不另加殉道身分。 |
| νεωκόρος | 庙务官／神庙管理人／守庙者 | 暂“庙务官”，保持其公共祭礼职务色彩；具体权限待核。 |
| μιαροφαγεῖν | 吃污秽之物／吃祭肉 | 暂前者，保留发言人的价值语气，不每次把语境中的祭肉补成词本身。 |
| παρρησία（IV.9） | 放胆／坦然／畅所欲言 | 在引述对方的语境，暂“放胆”；补充既有术语表的语境边界，不机械沿用信徒面对神的“坦然”。 |
| τελεσθῆναι（IV.11） | 参加祭仪／受入教礼 | 前者；祭仪性质待核，不擅加“秘密”。 |
| λόγος（IV.24） | 道／圣言／话语 | 神借以施行审判、与基督同位，依项目用“道”；原文没有ἅγιος，未加“圣”。 |
| γενέθλια（II） | 诞辰纪念／殉道纪念 | 保留“诞辰纪念”，说明具体纪念含义待核，避免未经辨年径改生日或忌日。 |

前三项、μιαροφαγεῖν及παρρησία语境补充登记项目表；其余仍为本书取舍，待更多证据后再决定是否全局采用。专名Πιόνιος沿用项目书名“皮奥尼乌斯”；Μακεδόνα按本版“马克多娜”；Πολέμων“波勒蒙”、Λίμνος“利姆诺斯”、Ἀσκληπιάδης“阿斯克勒庇阿德斯”暂用音译，通行中文名待核。
