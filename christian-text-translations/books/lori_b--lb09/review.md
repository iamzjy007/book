# 西里坦殉道者案录：校译附记

## B. 待核清单

| 位置、原文片段 | 问题 | 当前处理方式与下一步 |
|---|---|---|
| 1 `Claudiano`；校注 `Condiano U.` | 姓名异读影响年代人物识别。 | 正文按本版主文作“克劳狄安”；不悄改成另版“孔狄安”。同一执政官身份及读法待核。罗马日期保留原计数，不把换算日期加入正文。 |
| 2 `gratias egimus, propter quod imperatorem nostrum obseruamus` | propter quod的衔接可作因果或承接，不能借标点重写政治立场。 | 按本版停顿译“因此，我们也敬重我们的皇帝”；也可作“因此我们服从皇帝”。准确语用关系待核，未译成向皇帝献祭。 |
| 3—4 `simplex ... religio` / `mysterium simplicitatis` | simplicitas可指单纯、诚一；有接续总督用词的意味，未必是后世神学术语。 | 两处用“纯一”保持呼应；不补“神的单一性”或指定圣礼。词义待核。 |
| 5 `Initianti tibi mala de sacris nostris` | initianti结构生硬，可能含“开始说”或“引入奥秘”的双关。 | 以“你要开口诋毁我们的祭仪”译其最低限度语义；不增写总督接受教导的情节。句法和双关待核。 |
| 6 `imperium huius saeculi non cognosco` / `dominum meum et imperatorem regum omnium gentium` | “不承认统治”的范围及末句“我的主”的指向有解释分歧；本版措辞与通行“万王之王”并不相同。 | 忠实译“这世上的统治”“众王和万民的统治者”；不补“神圣性”、不套圣经称号。指称与异本关系待核。 |
| 12 `Libri et epistulae Pauli uiri iusti` | libri未列书名，不能断定是哪几卷圣经，也有把et作解释连接的读法。 | 作“书卷，还有义人保罗的书信”；不增“福音书”或“使徒”。所指待核。 |
| 15 `Hodie martyres in caelis sumus` | 现在时宣告与尚未处决之间的时态关系，martyres兼有见证语源。 | 保留“今日，我们在天上作殉道者”；不改写成关于灵魂去处的教义断语。修辞与精确词义待核。 |
| 16 `duci iussi` | 本句只说“命人带走”，处刑由前后文交代。 | 不在这句额外加“立即执行斩首”，保留17段处决。 |
| 17 `pro nomine Christi`；页下 `et ita omnes simul martyrio coronati sunt ... amen` | 主文短结尾，脚注另载较长结尾；BKV网页末尾另有Amen。 | 只译1902版主文到“为基督的名被斩首”；不拼入脚注的三一颂词，不补阿们。各异本结尾关系待核。 |
| 全篇人名 | 除常见专名外，本项目未做中文译名文献学调查。 | 用稳定工作音译；不得将它们冒称唯一通行译名。待核中文既有定译。 |

### 底本编者经文参照（不是案录正文）

印页24脚注对第9段列 `cf. Mt. 22,21 etc. Rom. 13,7`。保留为“参：太22:21等；罗13:7”，不把这些出处嵌入多纳塔的话，也不擅自把“等”补成其他经文。本篇未用和合本整句替换正文。

## C. 术语表增补建议

| 原词 | 可选译法 | 本次选择与理由 |
|---|---|---|
| genius | 守护神灵／守护神／精灵 | 守护神灵：保留皇帝祭仪语境，避免误作圣灵。 |
| simplicitas | 纯一／单纯／诚一 | 纯一：与3段simplex呼应，但具体词义保留待核。 |
| capsa | 箱／书匣 | 箱：原文未说明器物形制，不增“经卷匣”。 |
| gladio animaduerti | 以刀剑处死／斩首 | 判词用前者，17段decollati才明确作“斩首”。 |
| imperator regum | 众王的统治者／帝王之王 | 前者：不静默改译成另一拉丁读法rex regum。 |

- [全卷扫描](https://archive.org/details/actamartyrumsel00gebhgoog)；页图n38—n42对应印页22—26。逐页核读了全部拉丁主文；同页希腊异本未合译。页图URL、哈希和范围见source.json。
- 辅助对照：[BKV拉丁文本及德译](https://bkv.unifr.ch/de/works/-28x/compare/die-gerichtsakten-der-blutzeugen-aus-scili/1/passio-scillitanorum)、[档案所列旧英译](https://www.earlychristianwritings.com/text/scillitan.html)。这些不作为本次转译底本；正文不同处以1902版为准。
- 核读日期：2026-11-10 UTC。完整性：本版拉丁主文首尾齐全；未据全部手稿建立新校本，不能据此宣布传承史无异文。
- 本次性质：全文译毕并经译者逐句自校；B项仍未解决，非独立专家审定。
