# 术语表 v1

适用本项目；原语、语境和底本优先于机械统一。下列为项目暂定，新增争议放各书review.md；获新证据再记修订，不能全局盲替换。

| 原词 | 当前译法 | 边界与理由 |
|---|---|---|
| Deus / θεός（独一神） | 神 | 不改用“耶和华”，不增专名。复数诸神按“众神”处理。 |
| dominus / κύριος | 主；帝王称谓“陛下／君主”视句法 | 不能把对皇帝的dominus译成基督称号。 |
| Christianus / Χριστιανός | 基督徒 | 保留自称。拉丁/希腊性别形态不另补人物身份。 |
| martyr / μάρτυς | 殉道者；作动词按“作见证”语境 | 不把每一“见证”都译成殉道。 |
| episcopus | 主教 | 历史职分，不自动改成现代宗派职称。 |
| presbyter | 长老 | 可选“司铎”；此项目叙述古代职分暂用长老，非教义裁定。 |
| diaconus / subdiaconus | 执事／副执事 | 不合并两级。 |
| proconsul | 行省总督 | 罗马行政官称；不把所有prefect混同为此官。 |
| ἔπαρχος（罗马城） | 罗马城长官 | 保留与proconsul的差别。 |
| genius（皇帝祭仪） | 守护神灵 | 可选“守护神／精灵”；不是基督教圣灵。 |
| religio / εὐσέβεια | 宗教、敬虔／敬拜，按语境 | 祭仪语境不能强塞现代抽象宗教定义。 |
| mysterium | 奥秘 | 未指明具体圣礼时不译成“圣礼”。 |
| simplicitas | 纯一 | 兼有单纯、诚一含义；具体歧义列待核。 |
| confessio / ὁμολογία | 信仰告白／承认 | 法律承认、信仰告白分开。 |
| gratia / χάρις | 恩典；感谢语按句义 | Deo gratias译“感谢神”，不译“神的恩典”。 |
| παῖς θεοῦ | 神的仆人／神的儿子，待本段证据 | 不预先消除多义；首批游斯丁正文标待核。 |
| παρρησία | 坦然／坦然无惧 | 不扩大为免受审判保证。 |
| disciplina | 规训、规矩、法纪 | 教会规训与总督判词区分。 |
