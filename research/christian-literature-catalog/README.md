# 古代基督教文献与灵修经典书目研究

独立于翻译与审校的长期任务。目标是尽量客观地寻找仓库尚未完整收录、对认识早期基督教历史或灵修传统有价值的作品，保留可验证的书目与资源入口。只搜集信息，本阶段不翻译或下载全书。初建日期：2026-11-10（北京时间）。

入口：`PLAN.md`、`CONTINUATION.md`、`progress.json`、`queue.json`；第一阶段结果已保存：[优先18项](SHORTLIST.md)、[全部书目](CATALOG.md)、[阶段报告](PHASE-1-REPORT.md)，机器可读索引为 `catalog.json`。各工作者随查随存于 `workers/`，未经汇总的记录也可恢复。

“遗失”须区分已佚且只有引用、仅存残片、近代重新发现、存于未译手稿、现代读者不熟悉。新奇程度不等于历史可靠性或灵修价值。正统、非主流、伪托与后期重写均可研究，但必须说明其身份，不以信仰喜好抹去史料，也不把伪托作品当使徒亲著。

大陆正式出版、港台中文出版、网络译文、馆藏可见、可购买、未查得和未检索分别标记。任何一次搜索没有结果，都不足以断言中国大陆从未出版或中国信徒基本没听说。书目元数据与简介自主概述，不收整部现代译文。

任务不会自行读取套餐余额：当前没有可用的额度百分比接口，不能保证剩3%自动停。每批存档；真实额度或环境中断时保留断点并说明。日志、认领标签和队列不是后台服务；是否有代理运行须另外验证。

如需从已存工作记录重建目录，在仓库根目录运行 `python research/christian-literature-catalog/refresh.py`。它只汇总存档，不执行网络检索。
