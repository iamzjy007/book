# 近现代基督教书籍、档案与持续媒体研究执行计划

建立日期：2026-11-10（北京时间）。独立于古代文献研究。目标是建设可追溯、可续接、能服务中文系列文章选题的资源库。第一阶段偏重美国英文资料；长期不限国家、语种与教会传统。

## 范围与对象

近代暂以约1500年以后为范围，第一阶段重点19世纪至今。分为作品、作者／事工、档案馆藏、期刊、持续更新频道五类。同一作者的书、讲章库、播客与手稿需关联，不能计成同一种成果。覆盖福音派、改革宗、卫斯理／圣洁传统、五旬节／灵恩、主流新教、黑人教会、天主教、东正教和跨宗派资源；后续扩展拉美、非洲、亚洲、欧洲及非英语社区。

著名或影响力大是发现线索，不自动构成神学或事实可靠性的证明。记录可验证的出版史、机构地位、档案传承和传播渠道；没有可靠统计时不填受众人数或全球排名。作者归属、机构当前负责人、历史作者与后人整理必须区分。

## 阶段与交付

1. 库存和初筛：核仓库已有现代材料、官网身份、正式出版社／图书馆来源；形成第一阶段候选目录、阅读摘要、资源类型及来源。
2. 作品与版本深查：原作、修订、选集、译本分层，补ISBN／DOI／馆藏号（实际核过才填写）、年代、首版与新版、译者及中文可得性。
3. 持续媒体核实：逐一查官网、作者档案、栏目、日期、RSS／Atom／newsletter／播客feed、免费或订阅边界；实际订阅入口与已订阅是不同状态。不得凭更新频率宣传推断最近仍在更新。
4. 专题阅读：从候选资源选代表性材料阅读，区分出版方介绍、编辑摘要、实际全文阅读和二手评论；记录出处页码、段落或时间码。
5. 系列文章试编：完成选题卡、资料包、独立中文综述与校核，保存文章版本和引用记录。
6. 滚动维护：检查链接、栏目迁移、feed变化、已发表内容更正，按主题和时间增量更新。每阶段记录实际范围；全网无穷，不能宣布穷尽。

## 第一阶段分工与验收

书籍／作者12项、事工／讲章12项、手稿档案10项、跨传统灵修12项、刊物媒体12项、多元作者／宣教10项。允许有理由的增减；交叉重复保留别名后汇总。每条至少有标题、类型、简介／价值、来源及实际读取范围、中文状态、下一步。媒体另留订阅入口与更新证据，档案另留馆藏目录／影像／现场访问边界。

每3—5项保存一次独立worker文件。第一阶段验收是可查证的资源发现与执行计划，不等于通读所有书、已订阅频道、已获转载许可或已发表文章。

## 书目与媒体数据规范

每项使用稳定ID；保存原题、中文工作译名、作者／机构、国家／语言、传统背景、资源类型、内容摘要、预期价值、来源URL、访问日期和阅读层级。可选字段包括ISBN、版本、起止年代、馆藏号、feed地址、更新时间、付费状态、授权说明、中文对应资源和相关条目ID。未知项写待核，不编造。

库存标记分为已有全文、已有选段、只有介绍、未定位和未检索。中文出版按大陆、港台及其他地区区别；搜索不到不得写成未出版。公开网页不自动等于可全文转载，文章编撰优先自主综述、必要短引与原文链接；整篇翻译／转载需要查具体许可和授权条件。

## 更新与断点

建议编辑节奏：每周检查重点媒体与选题池；每月核重要书籍及档案新增；每季度复查机构归属、链接与代表性缺口。此为执行方案，尚未安装定时器或实际注册邮箱订阅。

持续媒体游标使用最后核过的文章规范URL、发布日期及栏目，必要时记录feed GUID；目录扫描使用作者／卷号／页码。不把抓取时间当文章发表时间，不用序号猜增量。修改过的旧文另记版本，失效链接保留历史证据。

任务状态为pending、in_progress、blocked、completed_for_scope；状态标签不证明工作者在运行。中断时原子保存有效JSON、最后读取位置、已查范围、障碍与下一操作。恢复先核实际文件与代理状态，保留所有已完成记录。额度百分比无可用接口，不承诺剩3%自动停。

## 系列文章编辑方案

拟设六个系列：①一本书的来历与核心问题；②祈祷与日常实践；③牧者讲章与处境；④手稿、书信与人物真实面貌；⑤全球教会与宣教记忆；⑥本月英文资源观察。每篇围绕一个可回答问题，不把多篇翻译拼接成原创。

选题卡记录目标读者、问题、选题依据、两至三项可核来源、原文阅读范围、不同传统观点、需要澄清的事实和预计篇幅。草稿包含背景、主要思想、原语／历史语境、可借鉴处、争议或限制、进一步阅读。涉及人物争议时用可靠一手记录和多方材料，准确归属，不重复未经证实的指控。

校核依次检查事实／日期／署名、引文与译义、上下文与不同版本、中文表达、链接及许可范围。可用既有style-guide的忠实自然原则；新闻、学术、访谈、祷告分别保留文体。文章不得冒充作者原文或未经说明使用合成引语。

产物依次为idea → researched → draft → reviewed → ready → published；本轮止于资源研究。正式发布平台、栏目命名、署名与发布权限尚待后续确定，不能把建议发布日程写成已运行的自动发布服务。

## 长期完整性与优先级

每季按时代×地区×语言×传统×文体做覆盖检查。优先有清楚版本、内容价值、可靠出处和中文补充意义的材料；热门与稀见兼顾。后续专门补非洲、拉美、亚裔、女性、残障与监狱事工等声音，避免把美国英文媒体版图当全球基督教全貌。

保留未收录／合并／排除及理由、访问失败与修订日志。衡量成果以实际核查的作品和资源、可复核证据和完成的文章为准，不以搜索命中数、粉丝数或链接总数替代质量。

## 执行批次与优先级

后续每批以可核成果为边界，不承诺固定工时或无穷扫描。第二阶段先选12项：4本书、3个持续频道、3组档案、2个补缺资源。每项补齐身份、实际内容样本、中文对应情况、访问边界和至少一个明确续查位置。第三阶段选其中6项，分别服务六个文章系列；每篇先完成资料包，再形成独立中文文章。第四阶段才进入稳定维护与地域扩展。阅读量以实际页数、章节、时长记录，不以抓取链接数代替。

排序采用五项各0—2分的辅助评分：主题相关性、原始资料可验证程度、版本及访问清晰度、对中文读者的补充价值、对当前目录覆盖缺口的改善。未知不评分、不当作低价值。评分只作工作排序，不能作为作品属灵价值或人物权威的量化排名；同分优先来源清楚、可读到正文且有具体问题的材料。

检索路线：作者／机构官网与正式出版社 → 大学及宗派档案 → 联合目录／国家图书馆与中文出版社 → 专题书目和可靠评论 → 博客及平台线索。书商页可提供版本线索，但应尽量用出版社和馆藏互证。订阅平台、视频平台和社交账号须先从官网确认归属。失效、付费、登录或地域受限项记录障碍，转查目录与馆藏，不虚写已读内容。

每批结束检查：稳定ID没有冲突；同书异版关系明确；每条有可追溯出处与阅读范围；中文出版判断有地区边界；最新日期来自真实内容；尚待核实项与下一步具体；文章和目录状态没有混淆。由汇总者对跨组重复和高风险事实复核，并用本地脚本校验数据、记录本次新增／合并／修正数量。

## 预期目录结构与责任

`workers/`保留调查证据和失败记录；`catalog.json`与`CATALOG.md`为汇总输出；`queue.json`保存待办与游标；`progress.json`记录真实阶段状态；`SESSION-LOG.md`记录批次变化；`EDITORIAL-PILOTS.md`保存选题样例。后续可增`reading/`资料包、`articles/`文章及`updates/`增量记录。研究者保存出处，汇总者核版本与重复，编辑者区分自己的综述和原文观点；这三种职责可以由同一会话依次承担。

续接命令：在仓库运行 `python research/modern-christian-resources/scripts/build_catalog.py` 重建现有记录；这只整理数据，不会自动联网搜集。每轮开始读取断点，每轮结束保存有效数据后提交。计划内的周期工作须有实际运行机制与可查询记录后，才可声称已启动。
